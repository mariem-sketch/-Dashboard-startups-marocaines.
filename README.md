# 📊 Analyse des Startups au Maroc — Power BI

## 📌 Description du projet

Ce projet consiste à analyser et visualiser les données relatives aux **startups marocaines** à l’aide de **Microsoft Power BI**.

L’objectif est de mieux comprendre la répartition des startups au Maroc selon plusieurs dimensions, notamment leur **ville d’implantation**, leur **secteur d’activité** et leur **phase de développement**.

Le projet s’appuie sur un jeu de données contenant **230 startups** et permet de transformer les données brutes en informations visuelles et facilement interprétables grâce à un tableau de bord interactif.

## 🎯 Objectifs

L’analyse cherche notamment à répondre aux questions suivantes :

* 🏙️ Quelles sont les villes qui comptent le plus de startups ?
* 📍 Comment les startups sont-elles réparties géographiquement au Maroc ?
* 💼 Quels sont les secteurs d’activité les plus représentés ?
* 🚀 Combien de startups se trouvent dans chaque phase de développement ?
* 📈 Quelle est la répartition des startups entre les phases **Idéation, Amorçage, Scaling et Internationalisation** ?
* 🔎 Quelle est la capacité des startups à évoluer vers les phases les plus avancées ?

## 🗂️ Données utilisées

Le dataset contient principalement les informations suivantes :

| Variable            | Description                          |
| ------------------- | ------------------------------------ |
| `Nom de la Startup` | Nom de la startup                    |
| `Ville`             | Ville d'implantation                 |
| `Secteur`           | Secteur d'activité                   |
| `Phase`             | Phase de développement de la startup |

Le jeu de données comprend **230 startups réparties dans plusieurs villes marocaines**, avec une forte concentration notamment à Casablanca, Rabat, Marrakech et Tanger.

## 🛠️ Technologies utilisées

* **Microsoft Power BI** — création du dashboard et visualisation des données
* **Microsoft Excel** — préparation et stockage des données
* **Power Query** — nettoyage et transformation des données
* **DAX** — création des mesures et indicateurs

## 📊 Dashboard

Le tableau de bord permet d'explorer les données de manière interactive à travers différents graphiques et indicateurs afin de faciliter l'analyse de l'écosystème des startups marocaines.

Les visualisations permettent notamment de comparer :

* la répartition des startups par ville ;
* la répartition par secteur ;
* la distribution selon les différentes phases de développement ;
* la concentration des startups dans les principaux pôles économiques du Maroc.
